# Map Markers — วาด Marker และเส้นบนแผนที่

เว็บแผนที่แบบ static สำหรับ **ปักหมุด วาดเส้น วาดพื้นที่ และวัดระยะทาง/พื้นที่** เปิดใช้งานได้ทันทีในเบราว์เซอร์
ไม่ต้องติดตั้งอะไร ไม่ต้องใช้ API key และวางบน GitHub Pages ได้เลย

🔗 **เดโม:** `https://<username>.github.io/<repo>/` (แก้เป็นลิงก์จริงหลัง deploy)

---

## ความสามารถ

| กลุ่ม | รายละเอียด |
|---|---|
| เครื่องมือวาด | จุด (Marker), เส้น (Polyline), พื้นที่ (Polygon), สี่เหลี่ยม, วงกลม |
| ระบุขนาดเป็น กม. | กรอกรัศมีในช่อง **"วงกลม / สี่เหลี่ยม — ระบุรัศมี (กม.)"** แล้วคลิกบนแผนที่ครั้งเดียว ได้วงกลมรัศมีตามที่ระบุ หรือสี่เหลี่ยมจัตุรัสที่ครึ่งด้านเท่ารัศมี (คลิกซ้ำวางได้หลายจุด) · เว้นว่าง = ลากวาดเอง · แก้รัศมีภายหลังได้ในป็อปอัปของวงกลม |
| ชุดวงแหวนรัศมี | วงกลมซ้อนกัน 4 วงในคลิกเดียว — โปรไฟล์สำเร็จรูป **1/2/3/4**, **1/2/5/10**, **5/10/15/20 กม.** หรือกำหนดเอง เลือกวางด้วยการคลิกบนแผนที่หรือวางกลางจอ พร้อมปักหมุดจุดศูนย์กลางและป้ายบอกรัศมีทุกวง |
| ย้ายตำแหน่ง | **ลากย้ายได้ทันทีทุกชิ้น** (หมุด เส้น พื้นที่ สี่เหลี่ยม วงกลม) ไม่ต้องสลับโหมด · ลากวงใดวงหนึ่งของชุดวงแหวน ทั้งชุดและหมุดศูนย์กลางจะตามไปพร้อมกัน · ปุ่ม **ย้ายได้** ใช้ล็อก/ปลดล็อกตำแหน่งกันลากพลาด |
| แก้ไข | แก้รูปทรง (ลากจุดหัก), ลบทีละชิ้น / ลบทั้งหมด / ย้อนชิ้นสุดท้าย |
| รายละเอียดต่อชิ้น | ตั้งชื่อ, ใส่โน้ต, เลือกสีได้ 8 สี (แก้ผ่าน popup ที่คลิกบนรูป) |
| วัดค่า | ระยะทางของเส้น, พื้นที่ + เส้นรอบรูปของ polygon, รัศมี + พื้นที่ของวงกลม — แสดงทั้ง **ตร.ม./ตร.กม.** และ **ไร่ / ตร.วา** |
| รายการ | แถบข้างแสดงทุกชิ้นที่วาด กดเพื่อซูมไปหา ซ่อน/แสดง หรือลบ พร้อมยอดรวมความยาวและพื้นที่ |
| แผนที่พื้นหลัง | **ภาพถ่ายดาวเทียม (ค่าเริ่มต้น)**, OpenStreetMap, สว่าง, มืด, ภูมิประเทศ |
| ค้นหา | ค้นหาสถานที่ (Nominatim) หรือพิมพ์พิกัด `13.7563, 100.5018` เพื่อกระโดดไป |
| อื่น ๆ | ปุ่มตำแหน่งฉัน (GPS), พิกัดเมาส์, สเกลบาร์, โหมดสว่าง/มืด, URL จำตำแหน่งแผนที่ (`#lat,lng,zoom`) เพื่อแชร์, รองรับมือถือ |

> ⚠️ **ไม่มีการบันทึกข้อมูล** — สิ่งที่วาดอยู่ในหน่วยความจำของหน้าเว็บเท่านั้น รีเฟรชหรือปิดแท็บแล้วจะหายทั้งหมด (ตามที่ออกแบบไว้)

## วิธีใช้

1. เลือกเครื่องมือจากแถบ **เครื่องมือวาด** แล้วคลิกบนแผนที่
   - เส้น/พื้นที่: คลิกไล่จุด แล้วคลิกจุดสุดท้าย (หรือจุดแรกสำหรับพื้นที่) เพื่อจบ
   - กด `Esc` เพื่อยกเลิกโหมดปัจจุบัน
2. คลิกที่รูปที่วาดแล้ว เพื่อเปิด popup ตั้งชื่อ ใส่โน้ต เปลี่ยนสี แก้รัศมี หรือลบ · **ลากรูปเพื่อย้ายตำแหน่งได้เลย** (กดปุ่ม "ย้ายได้" เพื่อล็อกไม่ให้ลาก)
3. ดูค่าที่วัดได้ในรายการด้านซ้าย และยอดรวมที่แถบล่าง

## โครงสร้างไฟล์

```
index.html          โครงหน้าเว็บ + แถบข้าง
css/style.css       ธีมสว่าง/มืด + responsive
js/measure.js       คำนวณระยะทาง/พื้นที่ (geodesic) และจัดรูปแบบหน่วย
js/map.js           สร้างแผนที่, แผนที่พื้นหลัง, พิกัด, ตำแหน่งฉัน, ธีม, URL
js/draw.js          เครื่องมือวาด/แก้ไข, ทะเบียนรูป, popup แก้ไขรายละเอียด
js/ui.js            รายการในแถบข้าง, ค้นหา, คีย์ลัด, โหมดมือถือ
```

## รันในเครื่อง

เปิด `index.html` ตรง ๆ ก็ได้ แต่แนะนำให้เสิร์ฟผ่าน http (ปุ่มตำแหน่ง GPS ต้องการ `localhost` หรือ `https`):

```powershell
python -m http.server 8787
```

แล้วเปิด http://localhost:8787

## Deploy ขึ้น GitHub Pages

```powershell
git remote add origin https://github.com/<username>/<repo>.git
```

```powershell
git push -u origin main
```

จากนั้นที่ repo บน GitHub → **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `/ (root)`** → Save
รอสักครู่จะได้ลิงก์ `https://<username>.github.io/<repo>/`
